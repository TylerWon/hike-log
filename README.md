# hike-log

## Development Set-up

To run the application locally, use docker compose: `docker compose up`. This runs the frontend, backend, and database
(PostgreSQL) in containers. The frontend is hosted on http://localhost:5173, while the backend runs on
http://localhost:8080.

See the [frontend README](frontend/README.md) and [backend README](backend/README.md) for more specific instructions.
